# Architecture Reporting Skill
## Purpose
Produce a structured architecture report from analysis and risk results.
## Inputs
Architecture profile and risk assessment.
## Processing
Combine evidence, findings, and limitations without altering the source observations.
## Outputs
A report object containing title, summary, architecture profile, risk assessment, and limitations.
## Limitations
Report quality depends on the completeness of repository evidence.
## Expected Behavior
Clearly distinguish observations from interpretations.
