# Architecture Reporting

## Purpose

Generate a clear and structured architecture report from repository analysis and identified risks.

## Inputs

- Architecture analysis results
- Architecture risk assessment results

## Process

1. Combine architecture observations with risk findings.
2. Summarize the detected technology structure.
3. Present identified risks with supporting evidence.
4. Document analysis limitations.
5. Produce a structured architecture report.

## Outputs

- Report title
- Architecture summary
- Architecture profile
- Risk assessment
- Limitations

## Limitations

The report reflects the available repository evidence and cannot independently reconstruct runtime behavior or undocumented external dependencies
